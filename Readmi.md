# Mi Portafolio Personal

## 👨‍💻 Sobre el proyecto

Este proyecto es mi portafolio web personal, creado como parte de una actividad de aprendizaje en desarrollo de software.

El objetivo es presentar información sobre mí, mis conocimientos, algunos de mis proyectos y una forma de contacto, utilizando tecnologías básicas de desarrollo web.

El portafolio está publicado en internet mediante **GitHub Pages**.

## 🚀 Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub
* GitHub Pages

## 📂 Estructura del proyecto

```text
Mi-Portafolio/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### `index.html`

Contiene la estructura y el contenido principal del portafolio.

### `style.css`

Contiene los estilos visuales de la página, incluyendo colores, tipografías, distribución, tarjetas, navegación y adaptación para dispositivos móviles.

### `script.js`

Contiene las funcionalidades interactivas desarrolladas con JavaScript.

## ⚡ Funcionalidades JavaScript

### 1. Mensaje de bienvenida

Se agregó un botón **"Saludar"** que muestra un mensaje de bienvenida mediante JavaScript.

Elegí esta funcionalidad porque permite tener una interacción sencilla con el usuario y hace que el portafolio sea más dinámico.

### 2. Modo oscuro

Se agregó un botón **"Modo oscuro"** que permite cambiar la apariencia de la página entre el modo normal y un modo oscuro.

Elegí esta funcionalidad porque mejora la experiencia del usuario y permite adaptar la visualización de la página según sus preferencias.

## 🎨 Diseño

El diseño utiliza una combinación de **blanco, blanco hueso, negro y dorado**, buscando transmitir una apariencia elegante, sencilla y profesional.

También se agregaron efectos visuales en los enlaces y proyectos para mejorar la interacción con la página.
